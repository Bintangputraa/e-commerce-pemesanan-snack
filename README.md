# E-Commerce Pemesanan Snack

Monorepo untuk proyek e-commerce pemesanan snack.

## Struktur Proyek

```text
.
├── Web/       # Aplikasi web Laravel + Inertia.js + Vue
└── Aplikasi/  # Aplikasi Kotlin (akan dikembangkan)
```

## Web

Aplikasi web utama berada di [Web/](./Web/). Dokumentasi instalasi, konfigurasi
Midtrans, fitur, endpoint API, dan perintah pengembangan tersedia di
[Web/README.md](./Web/README.md).

## Aplikasi

Folder `Aplikasi/` disiapkan untuk aplikasi Kotlin dan akan ditambahkan pada
pengembangan berikutnya.

## Kontribusi

Kerjakan perubahan sesuai folder proyek terkait. Jangan commit file rahasia
seperti `.env`, API key, atau kredensial pembayaran.

## Lisensi

Lihat lisensi pada masing-masing proyek.
